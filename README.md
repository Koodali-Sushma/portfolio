### 🌐 About this repository

This is my personal portfolio website, built with vanilla HTML, CSS and JavaScript (no frameworks or build step).

```
index.html                Homepage: hero, honeycomb menu, floating details card
about.html                About page (experience, education, interests)
css/styles.css            Styles (colours set as variables at the top)
js/data.js                Content: skills and projects
js/main.js                Renders content; honeycomb, card panels, screenshot viewer
assets/images/            Profile photo and icons
assets/images/projects/   Project screenshots
assets/documents/         Resume PDF
```

**Run locally:** open `index.html` in a browser, or run `python3 -m http.server 8000` and visit http://localhost:8000.

**Add or edit a project:** put screenshots in `assets/images/projects/`, then add an entry to `projects` in `js/data.js` with `images`, `repo` and `demo` (add `device: "mobile"` for phone screenshots). The comments at the top of that list explain each field.
