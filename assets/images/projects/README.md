# Project screenshots

Put project screenshots here, then list them in `js/data.js` under each
project's `images`. The first one is the card cover.

- Name them after the project: `plant-buddy-1.webp`, `plant-buddy-2.webp`, …
- About 1200–1600px wide, WebP or JPG, under ~200KB each
- Same shape for every cover (16:10 works best); the card shows the top of the image
- Blur any real names, emails or other personal data
